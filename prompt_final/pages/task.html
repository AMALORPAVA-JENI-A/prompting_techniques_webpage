Task

What is a Task in Prompt Engineering?

A task defines what exactly the AI should do. It is the core objective of a prompt. A clear task leads to focused and actionable output.

How to Define a Good Task

  • Use clear action verbs:
    • Explain, analyze, compare, generate, summarize, design, evaluate
  • Be specific and measurable, not vague or general
  • Focus on one primary objective per prompt
  • Match the task to your intended outcome

Common Task Types

  • Explain: Clarify a concept, break down complex topics, teach a skill
  • Analyze: Examine data, identify patterns, extract insights, assess trends
  • Compare: Identify differences and similarities between items or concepts
  • Generate: Create content, code, ideas, solutions, or creative work
  • Evaluate: Assess quality, effectiveness, risks, pros and cons

Best Practices

  • Write the task as an instruction, not a question
  • Avoid combining multiple tasks in one prompt
  • Clearly state the expected outcome
  • Place the task immediately after the role

Common Mistakes to Avoid

  • Using vague tasks (e.g., "tell me about")
  • Combining unrelated tasks
  • Expecting detailed output without specifying depth
  • Changing tasks mid-prompt

Example

Poor task:

"Tell me about data analysis"

Clear task:

"Analyze sales data and identify key trends and KPIs"

Simple Task Prompt Template

You are a [role]
Task: [specific action to perform]
Output: [desired format]
