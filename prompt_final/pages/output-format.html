Output Format

What is Output Format?

Output format defines how AI presents the answer. It ensures responses are readable, structured, and usable for your specific needs. The right format makes information actionable and easy to use.

What to Include as Output Format

  • Type: Text paragraph, table, JSON, bullet points, numbered list, code block
  • Layout: Columns, headings, numbering, sections, hierarchical structure
  • Level of detail: Summary, detailed, key points, comprehensive breakdown
  • Specific elements: Headers, subheaders, examples, footnotes

Best Practices

  • Match format to intended use (dashboard, report, presentation, documentation)
  • Keep instructions simple and clear
  • Use familiar structures (e.g., numbered lists, tables)
  • Test format with sample prompts first
  • Provide example output when possible

Common Mistakes to Avoid

  • Leaving format unspecified
  • Using unclear abbreviations or technical terms
  • Asking AI to output in multiple conflicting formats
  • Requesting format that doesn't match the task
  • Not providing enough detail about structure

Example

Without format:

"List KPIs."

With format:

"List 5 KPIs for a sales dashboard in a numbered bullet list with brief descriptions."

Common Output Format Types

  • Bullet points: For lists, key ideas, or summaries
  • Numbered list: For steps, procedures, or ranked items
  • Table: For comparing data, organizing columns, or structured information
  • JSON: For structured data, APIs, or programming
  • Paragraph: For narrative, explanations, or detailed descriptions
  • Code block: For programming examples or technical output
