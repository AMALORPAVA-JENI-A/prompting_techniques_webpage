Reasoning

What is Reasoning?

Reasoning means guiding the AI to think step-by-step. It helps the AI reach logical, accurate answers instead of guessing. Reasoning answers key questions that guide the problem-solving approach.

Key Questions Reasoning Answers

  • How should the AI solve the problem?
  • What steps should it follow?
  • What is the logical approach?

What to Include as Reasoning

  • Step-by-step instructions: Break down the task into numbered steps
  • Assumptions: State any assumptions needed for the task
  • Logical approach or method: Explain which approach to follow
  • Intermediate checkpoints: Show where the AI should evaluate progress

How to Write Reasoning Clearly

  • Break complex tasks into numbered steps
  • Use numbered lists or bullets for clarity
  • Keep sentences short and direct
  • Place reasoning before asking for the final output
  • Make each step actionable and specific

Best Practices

  • Use "think step by step" prompt
  • Combine reasoning with context when needed
  • Explain assumptions explicitly
  • Show intermediate steps when possible
  • Test reasoning with complex tasks first

Common Mistakes to Avoid

  • Asking AI to solve directly without reasoning
  • Leaving out intermediate steps
  • Providing vague or contradictory instructions
  • Skipping reasoning for simple tasks (though it helps)

Example

Without reasoning:

"Summarize this report."

With reasoning:

"First, identify key sales trends, then calculate month-on-month growth, and finally summarize in 3 sentences."

Simple Reasoning Template

Role: [role]
Task: [what to do]
Reasoning: [step-by-step guidance]
Output: [format]
